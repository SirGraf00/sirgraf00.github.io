Datenschutzerklärung – SirGraf Bots

Stand: 15. Oktober 2026

1. Verantwortlicher

Till Graf, Schweiz. Kontakt: mrtillsch@gmail.com

2. Zweck der App

SirGraf Bots ist eine private Automatisierung, die ausschliesslich vom Inhaber des YouTube-Kanals @SirGraf für die Verwaltung dieses eigenen Kanals genutzt wird. Die App nutzt die YouTube API Services.

3. Nutzung der YouTube API Services

SirGraf Bots verwendet die YouTube API Services. Mit der Nutzung dieser App erklären Sie sich mit den YouTube-Nutzungsbedingungen einverstanden. Es gilt zudem die Datenschutzerklärung von Google.

4. Welche Daten genutzt werden

Nach Zustimmung über die Google-Anmeldung greift die App auf folgende Daten des eigenen Kanals zu:

  • eigene Videos, einschliesslich privater und geplanter Videos
  • Metadaten wie Titel, Beschreibung, Tags, Kapitel, Thumbnails, Sichtbarkeit, Veröffentlichungszeitpunkt und Playlists
  • Untertitel bzw. Transkripte der eigenen Videos
  • Kommentare zu den eigenen Videos, um sie zu lesen und zu beantworten

Zusätzlich gibt es die App «SirGrafBot Chat»: Sie liest während Livestreams von @SirGraf die Live-Chat-Nachrichten über die YouTube API und antwortet im Chat als @SirGrafBot. Chat-Nachrichten werden nur für die Antwort verwendet und nicht dauerhaft gespeichert.

Die Daten werden nur genutzt, um den eigenen Kanal zu verwalten (Texte erstellen und setzen, Videos planen, Thumbnails hochladen, Kommentare beantworten). Es werden keine Daten fremder Kanäle oder anderer Nutzer gesammelt, ausser den öffentlich sichtbaren Kommentaren unter den eigenen Videos.

5. Speicherung

Das Zugriffstoken (OAuth-Token) wird ausschliesslich lokal auf dem eigenen Rechner des Inhabers gespeichert und nicht an Dritte übermittelt. Abgerufene API-Daten werden nur so lange zwischengespeichert, wie es für die jeweilige Aufgabe nötig ist, und anschliessend gelöscht bzw. regelmässig aktualisiert, wie es die YouTube API Services Developer Policies verlangen. Es werden keine Cookies gesetzt und keine Analyse- oder Werbedienste eingesetzt.

6. Weitergabe

Es findet keine Weitergabe, kein Verkauf und keine Nutzung der Daten für Werbung an oder durch Dritte statt. Die Nutzung der über Google-APIs erhaltenen Daten entspricht der Google API Services User Data Policy, einschliesslich der Anforderungen zur eingeschränkten Nutzung (Limited Use).

7. Widerruf und Löschung

Der Zugriff der App kann jederzeit über die Google-Sicherheitseinstellungen unter myaccount.google.com/permissions widerrufen werden. Nach einem Widerruf wird das lokal gespeicherte Token ungültig und gelöscht. Eine Löschung gespeicherter Daten kann zudem per E-Mail an mrtillsch@gmail.com verlangt werden.
